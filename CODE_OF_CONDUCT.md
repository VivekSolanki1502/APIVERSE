# Code of Conduct

## Our pledge

We want APIverse to be a welcoming, harassment-free project for everyone, regardless of experience, background or identity.

## Expected behavior

- Be respectful and constructive. Assume good intent.
- Give and receive feedback gracefully; critique code and data, not people.
- Back factual claims, especially about pricing, with official sources.
- Respect maintainers' time and project scope.

## Unacceptable behavior

- Harassment, discrimination, personal attacks, or insulting language.
- Publishing others' private information.
- Spam, self-promotion unrelated to the project, or submitting misleading or fabricated data (including fake pricing, reviews or verification claims).
- Any conduct that would be inappropriate in a professional setting.

## Enforcement

Maintainers may edit or remove comments, issues, pull requests and other contributions that violate this code, and may temporarily or permanently restrict participation. Report concerns privately to the maintainers using the contact method listed in `SECURITY.md`, or via a private channel on the repository host. Reports are handled confidentially where possible.

## Scope

This code applies to all project spaces (issues, pull requests, discussions) and to public representation of the project.

This document is a short, plain-language code of conduct inspired by widely used community standards such as the Contributor Covenant. Maintainers may adopt a longer standard text later.
